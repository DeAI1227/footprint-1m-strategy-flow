# 跟數夠不夠？（校準樣本）

日期：2026-09-02  
問題：第 2–6 天的 OKX 自組足跡，**根數是否太少**。  
結論：**是。59 根不夠凍結數字；224 根亞盤也不夠選 300 vs 400、不夠把 p25 寫成固定 SOL。**  
桶寬否定 0.10、忽略 0、200% 只記錄、堆疊定義 3——這些靠**定義 + 兩日 OHLC 幾何**，不是靠那 59 根。

資料來源維持不變：OKX `SOL-USDT-SWAP` 公共成交，`side=buy`→ask，`side=sell`→bid，`ctVal=1`（張 = 1 SOL）。這不是你的 ATAS 螢幕。

## 統計上：哪些結論穩、哪些是噪音

同一批 **224 根亞盤**、桶 0.01、Ignore Zero、最小量 = 該批非空單側 **p25≈28.8 SOL**（注意：59 根那小時 p25 曾是 **15 SOL**，絕對量已經跳了一次）：

| 比率 | 非空列失衡中位 | 3 檔棒 | Wilson 95% | 約每幾分鐘一個 |
|---|---|---|---|---|
| 200% 記錄 | 29% | 35/224（15.6%） | 11.5–21.0% | 6.4 |
| 300% Dale | 20% | 22/224（9.8%） | 6.6–14.4% | 10.2 |
| 400% Valtos | 14% | 14/224（6.2%） | 3.8–10.2% | 16.0 |

**300 與 400 的信賴區間重疊。** 在這 224 根裡，沒有統計權力宣布「SOL 用 300」或「SOL 用 400」。59 根上 9/59 vs 6/59 更沒有。

| 判斷 | 跟數夠不夠 | 為什麼 |
|---|---|---|
| 不要用桶 0.10 | **夠** | 2699 根 1m 高低：中位 9 tick，美盤中位 12；0.10 只剩約 2% 的棒跨得過 3 列。這是幾何，不是 59 根足跡 |
| 觀察桶先用 0.01 | **方法夠，美盤足跡尚未複核** | 亞盤 0.01 的 3 檔不是每根都有；美盤只靠 K 線高低推測「大概仍裝得下 3 檔」 |
| Ignore Zero = On | **夠** | 大佬定義 + 59 根就有 130 對 `0 vs 有量`。再多數不會把 On 改成 Off |
| 最小量 = 分位（p25 雙邊），不是 15 SOL | **規則夠，數字不夠** | 同一亞盤：59 根≈15 SOL，224 根≈29 SOL。寫死 15 就是把樣本噪音當常數 |
| 200% 只記錄、不武裝 | **方向夠** | 三檔裡永遠最忙；與 ATAS Learn 的 standard imbalance 一致。不靠 p 值選邊 |
| 武裝 300 ∥ 400 | **不夠選邊** | 區間重疊；缺美盤；缺第二個交易日 |
| 堆疊定義 3，4 當更嚴備註 | **定義夠，密度不夠凍結** | 3 來自 Dale/OFT 句子。4 檔約一半密度，樣本一變比例會跳 |
| 棒向一致 On | **定義夠** | Valtos 原句，不是從 59 根「看起來比較準」推的 |
| 當根 70% VA 畫得出來 / 不做 Naked POC | **夠** | 59/59 能達到 70%；不同 POC 價太多。 Naked 是外派，跟數再多也不做 |
| 未完成當進場 | **夠用來否決** | ATAS：1 分鐘本來就很多。第 7 天只數密度、不開倉 |
| 第 7 天凍結整張表 | **不夠** | 缺美盤足跡，300/400 不能鎖 |

## 要多少才算「可以凍結」

不是「再多拉 100 根亞盤」。缺的是**時段與交易日**，不是同一小時的重複。

| 目的 | 最低可用 | 仍不要凍結 |
|---|---|---|
| 亞盤 vs 美盤的 p25、3 檔密度 | 各至少一段完整活躍窗（亞 UTC 0–8、美 UTC 13–21），同一算法 | 單日仍可能碰到異常波動日 |
| 選 300 或 400 | 至少 **5 個交易日**、兩段時段都數；看 400% 在美盤會不會滿屏、在亞盤會不會整天 0 個 3 檔 | 單日美盤贏不能覆寫 Dale/Valtos 並列 |
| 把 p25 寫成 SOL 常數 | 不要。永遠重算分位。若要給軟體一個預設，至少跨一週的分位，並按時段分開 | 15 或 29 都只是快照 |
| 人看圖的 21×1 小時 | 那是讀圖練習時數，**不是**統計樣本。1 小時/天看 ATAS，跟 REST 自組 224 根是兩件事 |

粗算：要讓 10% vs 6% 的 3 檔率分開（300 vs 400 這種量級），單一時段也要 **數百到上千根** 已收盤 1m，而且還要第二個時段複核。224 根只夠說「400 比 200 稀」，不夠說「所以用 400」。
