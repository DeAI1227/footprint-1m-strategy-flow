# 第 6 天：SOL 當根 POC / 當根 70% VA

日期：**2026-09-07**（時程第 6 天；同一 59 根）  
固定：桶 0.01。POC / VA **不算失衡比率**，只用該棒成交量。  
出處：Orderflows 對**每一根 footprint** 算 POC 與 Value Area Percent **70% of that bar’s volume**。不是日盤 TPO，不做 Naked POC 清單。

算法（棒內）：POC = 量最大桶；從 POC 向相鄰較大量的一側擴，直到累積 ≥ 70%。只走相鄰，不跳空。

---

| 項目 | 59 根結果 |
|---|---|
| 能在相鄰擴張下達到 70% VA | **59/59** |
| Aligned POC（連續兩根 POC 同桶） | **4/58**（約 7%） |
| POC 在棒中位下方 / 中 / 上 | 33 / 3 / 23 |
| VA 中點在棒中位下方 / 中 / 上 | 30 / 7 / 22 |
| 不同 POC 價位數 | 35（59 根） |
| 棒高低差中位 | 約 8 tick |
| VA 寬度中位 | 3 tick |

判讀：

- 當根 POC / 70% VA **可以算、可以畫**，當位置修飾，**不當進場**。
- Aligned POC 在 1 分鐘上少見，出現就記，不編故事。
- 本樣本 POC 偏棒的下半，只是這段亞盤（漲棒較多）的描述，不是「低位吸籌 90%」。
- 35 個不同 POC：若做成 Naked 清單當磁鐵，就是噪音。**禁止 Naked POC。**
