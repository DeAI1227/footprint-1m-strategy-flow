# 九層數據與簡單 K 線：對讀指南（主例：掃流動性）

本文是填參數之後、開倉之前的**讀法課**。目的不是新腳本、不是新學派、不是九個儀表各投一票。

配套：

- `orderflow-footprint-school-guide.md`：足跡圖流派本身
- `orderflow-1m-tokyo-system-elements.md`：系統元素與契約
- `school-elements-expert-parameters.md`：專家出廠與教材數字
- 第 10 / 12 / 18 / 19 天觀察稿：套牢收回、CVD 衰竭、OI/強平否決、資金費黑窗

衝突時，以「客觀可計算、有失效條件」為準。本文不填新閾值，不改 300∥400，不晉升 live。

鎖定前提（與系統一致）：

- 主時鐘：1 分鐘已收盤 K 線。forming 只撤單 / 風控
- 執行所：OKX 自己的足跡定價。Binance / Bybit 只比方向，不看 A 打 B
- 位置只來自堆疊區、當根 POC/VA、近窗量堆、擺動。不是 ICT、不是 Kill Zone
- 制度層（OI、資金費、強平、熱圖）**只否決或改標籤**，不當進場主詞
- 「掃流動性」在本派已有名字：**腳本 C，失敗突破 / 套牢反向**。本文不另立腳本 H

一句話收斂：

> 厲害的短線不是把九個面板同時看熱。他們用最沒技巧的 K 線事件標出「止損被掃的地方」，再用九層裡頭**已經成交的那一半**判斷這場拍賣結束了沒有，用**還沒成交的那一半**判斷下一筆會不會被假牆騙走。大多數層是否決，不是開火。

## 0. 為什麼「簡單 K 線」反而夠用

K 線只留開高低收。它丟掉的東西，正好是足跡、CVD、盤口要還原的。所以單獨用 K 線形狀沒有因果。

可是 K 線有一件事做得很好，而且幾乎不需要技巧：

**所有人都能看見的高低點，就是止損與強平最容易堆在一起的地方。**

擺動高上面掛著突破單與空頭止損。擺動低下面掛著跌破單與多頭止損。價格去掃那一頭，K 線上就是一根刺出去的影線，或一根收在區外的突破棒。這就是文案裡的「掃流動性」。它毫無技巧，因為它只是去取用公開掛著的被迫單。

本派不否認這件事。本派否認的是後面那半句行銷：

- 「掃完一定反」——不一定。外面開始堆量，走腳本 D，不是 C
- 「熱圖亮區是磁鐵，去邊緣埋伏」——第 18 天已禁：不畫爆倉地圖、不獵 squeeze
- 「這是 ICT / SMC 結構」——區間用 Orderflows 的擺動 N，不是 BOS / CHoCH

簡單方法的完整句子是：

```
看得見的擺動沿被刺穿
    → 在 TRAP_BARS 根內收回區間
    → 九層告訴你：這是燃料燒完，還是新倉在外面開了
    → 寫得出失效，才叫交易
```

沒有收回，只有長影線，不叫掃完。第 10 天：單根長影線不算；必須先收在區外，再在 3 根內收回。過半數「收在區外」不會在 2 根內回來。

## 1. 九層不是九票，是一條因果鏈

把用戶列的 1–9 收成四層。層與層之間有方向，不能並列加權。

```
┌─────────────────────────────────────────────────────────────┐
│  K 線（簡單）：價格去了哪裡、有沒有收回                      │
│  只標位置與序列。不解釋「誰在打」                            │
└───────────────────────────┬─────────────────────────────────┘
                            │ 掃到了哪一頭？
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  I. 燃料與擁擠（制度，只否決）                               │
│  1 OI　2 Funding　3 Long/Short                               │
│  問：這波是在堆積燃料，還是在燒燃料？散戶是否擠在同一側？      │
└───────────────────────────┬─────────────────────────────────┘
                            │ 制度沒有否決整句話
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  II. 已成交的拍賣（本派眼睛，進場句子從這裡來）               │
│  4 CVD　5 Aggregated Volume　6 Footprint                     │
│  問：主動單有沒有推動價格？還是打在牆上走不動？               │
└───────────────────────────┬─────────────────────────────────┘
                            │ 句子對得上 A–G 其中一句
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  III. 尚未成交 / 正在被迫成交                                │
│  7 Heatmap　8 Real-time Liqs　9 Spot Orderbook               │
│  問：牆上的是布景還是真接？爆倉是高潮還是才剛開始？            │
└─────────────────────────────────────────────────────────────┘
```

讀法順序與學派第 12 章同一套，只是把九個名字嵌進去：

1. 資料品質（成交缺口、書健康、CVD 錨點是否聲明）
2. **層 I 制度**：清算、OI 急降、資金費黑窗、擁擠。可以整句否決
3. **K 線位置**：相對擺動區間、堆疊區、近窗量堆，這根在哪
4. **層 II 當根足跡**：delta、堆疊、excess、未完成、混亂
5. **層 III 盤口對讀**：牆補、撤、還是被真吃
6. 序列：發起、吸收、衰竭、套牢
7. 句子：只能對上 A–G 一句主句
8. 句號：寫不出失效就沒有進場

九層裡，**4、5、6 是主詞的證據；1、2、3、7、8 是標籤與否決；9 是對讀，不是單獨開火。** 把 7 當進場磁鐵、把 2 當方向、把 3 當主力訊號，都是把制度層偷做成腳本。

## 2. 每一層到底在量什麼（以及它量不到什麼）

### 2.1 Aggregated Open Interest（總計未平倉）

量的是：**現在還掛在場上的合約張數（或名義）。** 不是多空誰贏，不是成交量。

短線只准問兩句：

| OI | 價格 | 本派標籤 | 不准說的話 |
|---|---|---|---|
| 升 | 同向走 | 雙方在加倉，燃料在堆 | 「主力建倉，必續」 |
| 升 | 橫盤 | 對打加倉 | 「即將選擇方向」當進場 |
| 急降 | 單向加速 | `liquidation_regime` 或平倉驅動 | 「堆疊是成本區」 |
| 降 | 價也回 | 去槓桿，趨勢燃料變少 | 「OI 降就是頂」 |

第 18 天觀察用否決：SOL 1H OI 相對上一根 ≤ **−2%** → 那一小時新開倉關。SUI 同一語言、數字分表。5m ≤ −1% 只當加嚴旗標，不作獨立進場。

跨所加總的陷阱：三所 OI 可以加總來看「場上還有多少合約」，但**不能把三所成交加進同一張足跡**。OI 是制度標量；足跡是執行所定價。兩者層級不同。

OI 量不到的：誰是多、誰是空（要 3）、這筆成交是開倉還是平倉（要 8 + 價 + OI 一起看）、下一根會不會反（OI 不預測）。

### 2.2 Funding Rate（資金費率）

量的是：**永續多頭付給空頭（或反向）的擁擠稅。** 它慢，通常數小時結一次。

本派用法（第 19 天鎖死）：

- OKX 結算 **00:00 / 08:00 / 16:00 UTC**，前後 **±15 分鐘黑窗**，不開新倉
- 黑窗是時鐘，不是等「費率夠極端才關」
- **禁止用資金費符號當方向**
- 禁止把黑窗講成 Kill Zone / IPDA

正費率很高：多頭擁擠，之後的主動賣比較像抬轎者變市價逃，不是「空頭主力出手」。負費率很高：空頭擁擠，同理。擁擠只告訴你**反轉時同一批人會變成市價**，不告訴你反轉在這一根。

Funding 與 OI 的關係：高正費率 + OI 仍在升 = 擁擠還在加碼；高正費率 + OI 開始降 = 擁擠在拆，足跡上的賣比較像平多，不是新建空。同一張足跡，制度不同，句子就不同。

### 2.3 Long/Short Ratio（多空比）

通常有兩張表，必須分開，不能合成一個「多空情緒」：

- **人數比**：帳戶數。散戶權重大
- **持倉量比**：名義或張數。大戶權重大

短線可用的對照只有一種：人數擠在突破那一側，而持倉量比沒有一起擠，或大戶側相反。這是**擁擠標籤**，加到層 I，仍然不能單獨開倉。

量不到的：大戶下一筆要做什麼。持倉量比滯後、可被對沖、可被跨所拆倉。本系統目前沒有把 L/S 寫進硬否決表；沒有可靠流就標 `not_evaluated`，不准腦補主力。

### 2.4 CVD（累積成交量 Delta）

量的是：**主動買累積 − 主動賣累積。** 只含 taker。Maker 接單不進 CVD。

這是層 II 裡最容易被濫用的一條。正確用法（第 12 天）：

- 錨點必須聲明。本系統：每個 UTC 日時段起點重置（亞 0–8、歐 8–13、美 13–21、極薄 21–24）
- 兩日亞盤不可接成一條
- 句子是「價做時段新高（低），CVD 沒有同時新高（低）」
- **第一次衰竭預設不反手**。幾乎每個時段都會出現第一次背離

掃流動性時 CVD 怎麼用：

- 下掃擺動低：掃的那根 CVD 很負，收回的那根 CVD 不再更負或翻正 → 主動砸被接住，套牢成立多一票
- 下掃但 CVD 幾乎不負、價格卻崩了 → 掛單抽離，不是市價屠殺；先看盤口，不要說「沒人砸所以是假的」
- 上掃後價新高、CVD 不過高 → 可能衰竭（腳本 E），也可能只是被動買在牆上成交（CVD 看不見 maker）
- 爆倉單會把 CVD 打極端。極端 CVD + OI 急降，先說清算，再說背離

品質不好（重連、缺口）整段 CVD 作廢。

### 2.5 Aggregated Volume（跨所主動總成交量）

量的是：**這一分鐘（或這一秒）打出去的主動量有多大。** 本系統**不把三所成交加進同一張足跡**；跨所只比方向。所謂「聚合量」在本派落地時，是「各所各自的 1m 主動買賣 + 共振方向」，不是一張加總熱力圖。

短線只准當修飾：

- 突破、量在低分位：讓路或空簿，品質差，不追
- 高位放量但當根 POC 不遷移、推進變少：滯漲，靠近 E，不是單獨開空
- 掃穿當根量在高分位，收回那根量萎縮：比較像高潮結束，不是新趨勢的第一根

無量本身不是假突破的證明。薄時段本來就無量。先看時段，再看量的分位。

### 2.6 Footprint（腳印 / 簇狀圖）

量的是：**每個價位桶上，主動買與主動賣各成交了多少。** 這是本派主圖。K 線是它的壓縮檔。

掃流動性時，只問極端那幾個桶：

- 掃低：最低幾檔是厚量對向成交（excess / 吸收），還是薄量滑針？
- 有沒有賣失衡堆疊出現在推進過程，然後回踩時對向拒絕？
- 掃穿那根是不是混亂棒（雙向堆疊）？混亂只記錄，不開倉
- 極端是完成拍賣（低檔 Ask=0）還是未完成？未完成只在關鍵位修飾，不當進場（腳本 G）

失衡是斜對角，不是同一格左右互除。空桶不當 0 去除。單個失衡是噪音。堆疊用法是離開再回踩，不是當根追尖端。

「某個價位極高密度市價買卻漲不上去」——這是吸收，不是自動反轉。完整故事包含第二次打穿（腳本 B 的失效）。

### 2.7 Liquidation Heatmap（清算熱圖）

量的是：**用現有持倉與槓桿，估計哪些價位會觸發強制平倉。** 它是模型，不是成交。掛單可撤，槓桿可降，估計會過期。

本派允許的句子：

- 「這次掃穿的擺動沿外面，模型說有一叢強平」→ 解釋為什麼 K 線會去那裡
- 「掃到之後即時強平（第 8 層）對得上」→ 燃料確實在燒

本派禁止的句子（第 18 天原文精神）：

- 把強平量大的價當磁鐵去埋伏
- 為了「抓反轉」把失衡調到 450%
- 不畫爆倉地圖、不獵 squeeze
- 拿不到強平流就腦補地圖；應標 `liq_stream_missing`，只靠 OI + 單向加速否決

熱圖是層 III 的**背景**，用來理解掃穿為什麼發生。進場仍然要等收回 + 足跡 + 非清算制度。

### 2.8 Real-time Liquidations（即時爆倉）

量的是：**正在被強平的名義與方向。** 這是已發生的被迫成交，比熱圖真實，但仍不是建倉。

與 OI、足跡的三角：

| 即時強平 | OI | 足跡巨量主動 | 標籤 |
|---|---|---|---|
| 爆發 | 急降 | 同向極端 | `liquidation_regime`：堆疊 ≠ 建倉；逆勢接刀硬否決 |
| 爆發後迅速沒有 | 降速變緩 | 極端出現 excess | 瀑布可能結束，**另一場**拍賣才開始 |
| 幾乎沒有 | 升 | 同向堆疊 | 比較像自願加倉，才准談 A/D/F |
| 單邊持續 | 仍降 | 每根都創新極端 | 還沒結束，不准抄底摸頂 |

第 18 天：該 1m OKX 強平名義 ≥ 當批樣本 p95 → 當根及鄰近 forming 新開倉關。文案「爆倉高潮立刻反向開倉」正好是這條否決要擋的。高潮當根滑點最壞，標記價與 last 最容易打架。

### 2.9 Spot Orderbook（現貨掛單簿）

量的是：**現在願意掛、隨時可撤的限價量。** 期貨合約製造短線波動；現貨牆比較像真正的地板與天花板——前提是牆在靠近時選擇留下。

本派四種對讀（腳本 F，書不健康則整句 `not_evaluated`）：

1. **真吃牆**：成交核對為啃掉掛單，1m delta 同向 → 順突破原料
2. **讓路**：牆先撤，足跡空，價格飄過 → 否決，不追
3. **吸收牆**：市價打在牆上，價格不穿，牆補 → 反轉原料，準備第二次打穿
4. **假牆陷阱**：攻擊開始後牆撤，價格加速 → 次主流比教科書吸收更常見

靜態大牆預設布景。Spoofing 的可觀測外觀就是「遠離時很大、靠近時撤」。現貨牆被期貨掃單吃掉，常常是掃流動性的啟動，不是結論。

現貨與合約必須分開看：現貨大買牆擋住的是現貨 taker；合約可以靠標記價與強平繼續打穿。對讀時，執行所合約足跡仍是進場價位的唯一來源。現貨只解釋「這頭有沒有真實現貨需求在接」。

## 3. 層與層怎麼對話（關係，不是清單）

記住六組對，比記住九個定義有用。

### 3.1 OI × 成交量 × 即時強平 = 燃料診斷

這是「這波行情靠什麼在走」的第一問。

```
價在走 ＋ 量在放 ＋ OI 升 ＋ 強平不大
    → 自願加倉。足跡上的同向堆疊可以當路徑，離開後才是位置。

價在走 ＋ 量在放 ＋ OI 急降 ＋ 強平爆發
    → 燃料在燒。同一張堆疊改掛 liquidation_regime。
      不准做「主力成本區回踩」（A 的誤用）。
      不准做「吸收抄底」（B 的誤用）。

價在走 ＋ 量很小 ＋ OI 不動
    → 空簿或讓路。F 若看見牆撤，整句否決。
```

掃流動性要的是第二種的**尾聲**，不是第二種的**中段**。中段接刀 = 否決。尾聲的客觀近似：強平從 p95 掉下來、OI 不再用 1H −2% 的速度掉、掃穿那根出現厚量 excess、下一根收回區間。四樣不必同時完美，但強平還在 p95 時不准猜尾聲。

### 3.2 Funding × 多空比 × OI = 擁擠，不是方向

三個都偏多：場上很多人付錢當多頭。之後若出現掃高收回，空單比較像在收割擁擠，而不是「費率說要空所以空」。

三個都偏空：掃低收回才比較像軋空尾聲。

費率結算黑窗裡，即使 C 的收回成立，仍否決新開倉。第 19 天：黑窗裡棒向一致 3 檔大約少一半，**不是沒有**——所以更需要時鐘，不是把比率加嚴去獵殺結算。

### 3.3 價格 × CVD × Footprint = 背離的唯一合法位置

行銷把 CVD 背離畫滿全圖。本派只在兩處看：

1. 關鍵位（堆疊沿、近根 POC、近窗量堆沿、擺動沿）—— Dale 的限制
2. 已經在走的發起末端——腳本 E，第一次不反手

掃流動性把這兩處疊在一起：擺動沿就是關鍵位。掃低時你要看的不是「全日 CVD 與價格的大背離」，而是：

- 掃穿那根：主動賣有沒有打在最低幾檔、價格有沒有繼續走
- 收回那根：delta 是否不再 innovate 新低
- 時段 CVD：有沒有跟上這次新低

價新低 + 時段 CVD 未新低 + 最低檔厚量對向 = 吸收 / 衰竭修飾，給 C 或 B 加確認。  
價新低 + CVD 更負 + 最低檔薄量滑過 = 空簿，不是莊家拒絕。

### 3.4 Footprint × 掛單簿 = 吸收還是冰山還是布景

只看足跡會把已經消失的攻擊當成還在的支撐。只看盤口會被假牆訓練出反向條件反射。

掃低的經典對讀：

| 足跡（已成交） | 盤口（可撤） | 句子 |
|---|---|---|
| 大量主動賣，價格不破 | 現貨 / 合約 bid 牆在補 | 吸收牆。B 的原料。第二次打穿是句號 |
| 大量主動賣，價格不破 | 牆在撤 | 不是吸收，是讓路前兆。否決做多 |
| 薄量主動賣，價格破了 | 牆早就沒了 | 空簿滑針。不叫掃流動性成功 |
| 主動買開始出現在原牆價 | 牆被真吃 | 真突破，走 F 或等 D，不要做 C 的反向 |

冰山只是推論：可見量小，該價累計成交遠超可見量且牆反覆補。次主流做市補貨也長這樣。只確認，不主觸發。

### 3.5 熱圖 × 即時強平 = 預測對上現實

熱圖說「下面有一叢多頭強平」。價格掃下去。此時只准核對：

- 即時強平有沒有真的噴出來？沒有 → 模型錯了或槓桿已被降，不要因為顏色還在就再等一刀
- 噴出來之後有沒有停？沒停 → 制度否決，不是「再掃深一點就反」
- 噴出來、停了、K 線收回、足跡出現對向 excess → 這才回到腳本 C 的世界

熱圖先被掃、即時強平對得上，只解釋「為什麼這根影線存在」。它不代替收回。

### 3.6 簡單 K 線 × 九層 = 位置對證據

K 線負責問：「有沒有客觀沿被刺穿、有沒有收回？」  
九層負責問：「這次刺穿是燒燃料還是開新倉？收回那根是拒絕還是停頓？」

任何一層單獨出現都不開倉。這與學派第 19 條契約同一句：單因子不開倉。

## 4. 主例：掃流動性（腳本 C）怎麼把九層疊上去

### 4.1 K 線上長什麼樣子（沒有技巧的那一半）

客觀序列，與 `eval_c`、第 10 天同一套：

1. 用擺動 N（觀察起點 5）標出當前區間高 `range_high`、低 `range_low`
2. 至少一根已收盤 1m **收在區外**（上破或下破）
3. 之後 `TRAP_BARS` 根內（觀察用 3）**收回到區內**
4. 外面沒有開始連續堆 POC——堆了就偏腳本 D，不要硬做 C

這就是掃流動性。刺出 = 去取用沿外的止損與強平。收回 = 那批追價單被困。

第 10 天數字只說明密度，不是勝率：153 次收在區外，TRAP=3 收回 45%。美盤兩根內只收回 29%。所以「影線反轉」會更糟。

### 4.2 下掃後做多：九層檢查表

假設 K 線已經滿足：收在 `range_low` 下，然後 3 根內收回。現在才打開九層。預設答案是「否決」，每一層要主動把否決拿掉。

| 順序 | 層 | 准做 C 多的樣子 | 否決 / 改走別句 |
|---|---|---|---|
| 0 | 品質 | 成交完整、OKX 書可用或 F 標 `not_evaluated`、CVD 錨點是本時段 | 缺口、重連未暖機、書壞還硬看牆 |
| 1 | OI | 掃的那一小時**沒有** 1H ≤ −2%；或急降已經發生在掃穿當根、現在不再用這個速度掉 | 當前 1H 仍 ≤ −2%：整小時關（第 18 天） |
| 2 | Funding | 不在 ±15m 黑窗；不把負費率當成「該做多」 | 黑窗；用費率符號當方向 |
| 3 | L/S | 可缺。若有：人數比仍偏空、掃完沒有立刻翻多，只當擁擠確認 | 單獨拿人數比開倉 |
| 4 | CVD | 掃穿根主動賣在，收回根不再創新低；時段 CVD 未確認新低更佳 | 收回後 CVD 繼續創新低；或 CVD 因缺口作廢還拿來背離 |
| 5 | Volume | 掃穿根量相對該時段偏高，收回根不再放量向下 | 薄時段無量滑針當「莊家掃完」 |
| 6 | Footprint | 最低檔厚量對向或吸收；不是混亂棒；堆疊若出現，是賣堆疊被留在區外當被困痕跡 | 雙向堆疊；最低檔薄量空洞；把賣堆疊當「下方鐵板」去買 |
| 7 | Heatmap | 最多用來解釋「為什麼去那裡」。掃到模型叢之後即時強平對得上 | 在亮區邊緣提前埋伏；沒強平流卻畫地圖 |
| 8 | 即時強平 | 掃穿分鐘可以高，但**當根不得仍 ≥ p95 還開新倉**；要等高潮過 | 「高潮當根抄底」（第 18 天否決） |
| 9 | 盤口 | 收回時 bid 近端在補或至少沒讓路；現貨大買牆若還在，只確認，不把牆後當止損 | 讓路突破當吸收；止損躲在可見牆後（第 13 天禁令） |

通過之後，主句只有一句：**腳本 C，下破後收回，做多。**  
確認可以有：OKX delta 翻正、非極薄、VA 有利側。確認不能單獨開倉。  
句號（失效）：再次收在 `range_low` 下，且外面開始堆 POC（交給 D 的世界，C 認輸）。

### 4.3 上掃後做空：鏡像

把上表高低對調。多一個擁擠檢查：若資金費持續偏正、OI 剛升過一波，上掃收回比較像收割抬轎；若資金費平、OI 在升、外面 POC 連續在區上，那是 D 不是 C。

### 4.4 掃了但不要做 C 的三種常見結局

厲害的人不是掃了就反手。他們用同一套 K 線，分出三種句子：

```
刺出 → 收回、外面沒堆量、制度沒否決
    → C（套牢反向）

刺出 → 不收回，外面連續 POC / 桶量堆積
    → D（被接受，等回踩舊沿）。此時做 C 就是逆勢

刺出 → 強平 p95 + OI 急降，還在單向
    → 什麼都不做。liquidation_regime
```

腳本 A/B/E/F/G 是同一事件的**別種讀法**，不是同時開火：

| 你看見的 | 實際該說的句子 | 不要說 |
|---|---|---|
| 先有賣堆疊且已離開，掃低剛好打回堆疊區，當根拒絕 | **A** 回踩，C 只是外觀 | 「又掃流動性又回踩，雙倍開倉」 |
| 掃在近窗量堆沿 / POC，大量主動賣不破 | **B** 吸收；第二次打穿是句號 | 「吸收 = 底部」 |
| 趨勢已經走一截，掃的是時段新高，CVD 沒跟上 | **E** 衰竭，第一次只減倉 | 「背離反手」 |
| 牆上的空頭牆被真吃，delta 同向，收回失敗 | **F** 真吃牆，順突破 | 「讓路也當 F」 |
| 掃的極端兩邊都有成交（未完成），且落在關鍵位 | **G** 只當目標 / 修飾 | 「未完成當進場」 |

同一標的同一時間只准一句主句。C 與 D 互斥（第 10–11 天：TRAP=5 會跟 D 搶事件，所以 TRAP 停在 3）。

## 6. 厲害的人實際上少看了什麼

把「大佬」從文案裡還原成本派能執行的習慣。

1. **先標沿，再等沒技巧的事件。** 沿來自擺動與堆疊，不是來自九個振盪指標。事件就是刺出與收回。他們不預測什麼時候掃，他們等掃發生。
2. **九層裡大半是否決。** OI、費率、強平、薄時段、混亂棒、壞書，拿掉之後，真正能開火的 1 分鐘很少。第 18 天：231 根棒向一致 3 檔裡，OI/強平否決約 16 根——這是觀察窗裡的比例，不是「否決很少所以能忽略」。
3. **進場主詞永遠是拍賣狀態，不是情緒。** 收回那根的 footprints：拒絕、吸收、delta。Funding、L/S、熱圖從不單獨產生主句。
4. **同一事件只說一句話。** 掃完收回就說 C。不要同時說「CVD B 背離 + 熱圖磁鐵 + 費率過熱 + 堆疊鐵板」。加詞不會加勝率，只會讓失效寫不清楚。
5. **失效先寫。** C 的句號是「再次收在區外且外面被接受」。B 的句號是「第二次打穿」。E 的句號是「再次發起且 CVD 跟上」。寫不出句號的 overlay 組合，不是交易。
6. **承認第一次常常是錯的。** 衰竭可以衰竭三次。吸收後面常有第二次打穿。套牢可以套兩次才真走。這不是悲觀，這是 1 分鐘次主流的病理（學派第 10 章）。
7. **現貨牆與合約爆倉分開。** 合約可以把價格打到現貨牆裡去吃強平；現貨牆沒撤也不等於合約多頭安全。執行價位仍用 OKX 合約足跡。

他們看起來「只用掃流動性」，是因為 K 線事件簡單。看起來「結合很深的數據」，是因為否決層很深。深度不在進場花樣，在**不准做的時候更多**。

## 9. 讀完應該能做到的事

能指著一根普通 1 分鐘陰線，說出它是「區間內對打、下破尚未收回、下破已收回、還是清算瀑布中段」。
